# Mission Reflection

Among the three cloud platforms, Google Cloud impressed me the most because of its strong features for Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. I also found it interesting that Google Cloud offers Compute Engine for virtual machines and Google Kubernetes Engine (GKE) for managing containerized applications.

AWS, Azure, and Google Cloud have many similarities. All three provide services for computing, storage, networking, databases, security, and identity management. They also allow organizations to use cloud resources without maintaining all the physical hardware themselves. However, each platform has its own strengths, so one provider may be a better choice depending on the needs of an organization.

Business requirements are important when choosing a cloud platform. An organization should consider its budget, existing technologies, application needs, security, scalability, location, and available technical skills. For example, Azure is a good choice for organizations that already use Microsoft technologies, while Google Cloud can be a strong option for projects involving AI, Machine Learning, and Kubernetes.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not only about picking the most popular platform. I need to understand the client's needs first and compare the services that can best solve their problems. I also learned that different clients may need different cloud platforms depending on their goals and resources.

After completing this mission, my GitHub Cloud Computing Portfolio became more organized and informative. I added research about AWS, Azure, and Google Cloud, comparison tables, client recommendations, and my reflection. This activity helped me better understand cloud computing and how different cloud platforms can be applied to real-world business needs.
