# AWS Research

## Brief Overview
AWS is a cloud computing platform from Amazon that provides different services for computing, storage, databases, networking, security, and other IT needs. It allows organizations to use cloud resources without having to build and maintain all the physical infrastructure themselves.

## Global Infrastructure
AWS has a worldwide infrastructure made up of Regions and Availability Zones. This helps organizations place their applications in suitable locations and improve availability and performance.

## Cloud Management Console
The AWS Management Console is a web-based interface where users can create, configure, monitor, and manage AWS resources.

## Four Core Services:
•	Amazon EC2 – provides virtual servers for running applications.
•	Amazon S3 – provides object storage for files and data.
•	Amazon VPC – provides a private virtual network for cloud resources.
•	AWS IAM – manages users, permissions, and access to AWS resources.

## Three Advantages:
•	It offers a wide variety of cloud services.
•	It can scale resources depending on the needs of an organization.
•	It has a large global infrastructure.

## Typical Enterprise Use Cases
AWS can be used for websites, mobile applications, databases, backups, data analytics, enterprise systems, and other applications that need reliable and scalable cloud resources.
