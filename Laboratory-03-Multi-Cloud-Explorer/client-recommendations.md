# Client A – Startup Company

## Recommended Platform: AWS
I recommend AWS because it can support a startup as it grows. The company can begin with the resources it needs and increase them as more users start using the mobile application. AWS also provides many services that can be combined to build and support an application without maintaining physical servers.

### Three possible services:
-	Amazon EC2
-	Amazon S3
-	Amazon RDS

# Client B – University

## Recommended Platform: Microsoft Azure
I recommend Microsoft Azure because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure is designed to work well with Microsoft's existing technologies, which can make the transition to cloud services easier. It can also help the university manage identities, applications, and other resources in one environment.

### Three possible services:
-	Azure Virtual Machines
-	Microsoft Entra ID
-	Azure SQL Database

# Client C – AI Research Company

## Recommended Platform: Google Cloud
I recommend Google Cloud because the company's main needs are Artificial Intelligence, Machine Learning, and high-performance computing. Google Cloud provides services and computing resources designed for these workloads. It also supports GPUs and other accelerators that can be useful for demanding AI and research tasks.

### Three possible services:
-	Compute Engine
-	Vertex AI
-	Google Kubernetes Engine (GKE)

# Client D – Global E-Commerce Company

## Recommended Platform: AWS
I recommend AWS because a global e-commerce company needs a platform that can handle many users and changing levels of traffic. AWS provides global infrastructure and scalable services that can help keep the website available while demand increases. This makes it a practical choice for an online business serving customers in different locations.

### Three possible services:
-	Amazon EC2
-	Amazon S3
- Elastic Load Balancing

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | GCP | Provides scalable infrastructure and useful development services for growing applications. |
| Enterprise Organization | AWS | Offers a broad range of enterprise cloud services and global infrastructure. |
| Microsoft Environment | Azure | Provides strong integration with Windows Server, Microsoft 365, and Microsoft Entra ID. |
| AI / Machine Learning | GCP | Provides strong AI, machine learning, and data analytics capabilities. |
| Kubernetes Deployment | GCP | Google Kubernetes Engine provides a managed Kubernetes platform. |
| Global Web Application | AWS | AWS provides global infrastructure and services suitable for highly available applications. |
