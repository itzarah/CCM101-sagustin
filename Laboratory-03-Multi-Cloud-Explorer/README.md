# Linux Investigation

## Important
The exact Operating System, CPU, memory, and disk-space results depend on the Linux environment that you actually launch in KillerCoda. These values should not be invented.

### Use the following commands in the KillerCoda terminal:
- uname -a  – Operating System / kernel information
- lscpu  – CPU information
- free -h  – Memory information
- df -h  – Disk-space information

After running the commands, take a screenshot of the terminal and include it in the required screenshots folder. Record the actual results in your README.md.

## Question: If this Linux server were migrated to the cloud, which AWS, Azure, and GCP services could host it?

Answer: The Linux server could be hosted using Amazon EC2 on AWS, Azure Virtual Machines on Microsoft Azure, or Compute Engine on Google Cloud. These services provide virtual machines that can run Linux operating systems. The best option would depend on the client's budget, requirements, existing technologies, and preferred cloud platform.
