# Cloud Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Google Cloud IAM |
| Primary Strength | Wide range of services | Microsoft enterprise integration | Data analytics, AI, and Kubernetes |
| Ideal Organizations | Startups and enterprises | Microsoft-based organizations | Data-driven and cloud-native organizations |

## Question 1: Which cloud provider offers the broadest range of services?
Answer: I would choose AWS for this category because it has a very broad collection of cloud services. It covers areas such as computing, storage, databases, networking, security, analytics, and AI, giving organizations many options for different types of projects.

## Question 2: Which provider best integrates with Microsoft technologies?
Answer: Microsoft Azure is the best choice for organizations that already use Microsoft technologies. Since Azure is developed by Microsoft, it works closely with products such as Windows Server, Microsoft 365, Microsoft Entra ID, and SQL Server.

## Question 3: Which provider is strongest in Artificial Intelligence and Kubernetes?
Answer: Google Cloud is a strong choice for Artificial Intelligence and Kubernetes. It provides AI and Machine Learning services and Google Kubernetes Engine (GKE), which helps organizations deploy and manage containerized applications.

## Question 4: Which cloud platform would you personally choose and why?
Answer: I would personally choose AWS because it offers many different services and can support both small and large applications. As an IT student, I also think it would be useful for learning because it covers important areas such as computing, storage, networking, databases, and security.
