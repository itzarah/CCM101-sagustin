# Google Cloud Platform (GCP)

## Brief Overview
Google Cloud Platform (GCP) is Google's cloud computing platform. It provides services for computing, storage, databases, networking, data analytics, Artificial Intelligence, and Machine Learning.

## Global Infrastructure
Google Cloud has a worldwide infrastructure made up of regions and zones. These locations allow organizations to deploy applications in different parts of the world and improve availability and performance.

## Cloud Management Console
Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources.

## Four Core Services:
-	Compute Engine – provides virtual machines for running workloads.
-	Cloud Storage – provides scalable object storage for data and files.
-	Google Cloud VPC – provides virtual networking for cloud resources.
-	Google Cloud IAM – controls identities, roles, and access permissions.

## Three Advantages:
-	It has strong Artificial Intelligence and Machine Learning capabilities.
-	It has strong support for Kubernetes and containerized applications.
-	It provides powerful data analytics services.

## Typical Enterprise Use Cases
GCP can be used for AI and Machine Learning projects, data analytics, web applications, containerized applications, and high-performance computing. It is especially useful for organizations that work heavily with data and modern cloud-native technologies.
