# Microsoft Azure

## Brief Overview
Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, databases, networking, security, Artificial Intelligence, and application development.

## Global Infrastructure
Azure has a large worldwide infrastructure with many regions and data centers. This allows organizations to deploy applications closer to their users and choose locations that fit their business and compliance needs.

## Cloud Management Console
The Azure Portal is a web-based interface used to create, configure, monitor, and manage Azure services and resources.

## Four Core Services:
-	Azure Virtual Machines – provides virtual servers for applications and workloads.
-	Azure Blob Storage – stores large amounts of unstructured data such as files and images.
-	Azure Virtual Network – provides networking between Azure resources.
-	Microsoft Entra ID – manages identities, authentication, and access to resources.

## Three Advantages:
-	It works well with Microsoft products and technologies.
-	It provides a large global infrastructure.
-	It is useful for enterprise and hybrid cloud environments.

## Typical Enterprise Use Cases
Azure is commonly used for Windows Server workloads, Microsoft-based business systems, databases, Microsoft 365 environments, AI applications, and hybrid cloud setups. Its integration with Microsoft's existing technologies can make cloud adoption easier for organizations already using Microsoft products.
