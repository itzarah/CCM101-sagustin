During Mission 6, I learned how Docker Compose can make cloud deployment easier and more organized. Creating a "docker-compose.yml" file allows multiple containers to be configured and deployed using just one file. Instead of manually creating and configuring each container, Docker Compose can start the related services together.

I also learned that YAML requires proper spacing and indentation. When there is an indentation error, Docker Compose may not be able to read the configuration file and can show a YAML parsing error. This taught me to be more careful when writing configuration files.

Another thing I learned is the use of environment variables such as "MYSQL_PASSWORD". These variables provide important configuration values needed by the containers. They also make the configuration easier to manage and change when needed.

Deploying Nextcloud in just a few minutes felt convenient because Docker Compose made the process faster and easier. I did not have to manually install and configure every component separately. It helped me understand how containers can simplify the deployment of applications and services.

Since Mission 1, my understanding of cloud computing has changed. I now understand that cloud computing is not only about using online services. It also involves infrastructure, storage, containers, networking, and applications. I also became more comfortable using Linux commands and Docker. Overall, this mission helped me improve my technical skills and gave me a better understanding of how cloud applications can be deployed.
