# Mission Overview

In this laboratory, I deployed a private cloud storage system using Nextcloud and MariaDB. I used Docker Compose to create and manage the application and database containers.

# Objectives

- Understand two-tier architecture.
- Create a Docker Compose configuration.
- Deploy multiple containers.
- Connect Nextcloud with MariaDB.
- Access Nextcloud through a web browser.
- Practice using Linux and Docker commands.

# Tools Used

- Docker
- Docker Compose
- Nextcloud
- MariaDB
- Ubuntu
- KillerCoda

# Skills Learned

I learned how to use Docker Compose to deploy multiple containers and connect an application to a database. I also improved my Linux command-line, Docker, YAML, and technical documentation skills.
