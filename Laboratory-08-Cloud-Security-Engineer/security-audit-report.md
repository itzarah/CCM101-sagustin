# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

### The Principle of Least Privilege means giving users only the permissions they need to perform their tasks. It is important in cloud computing because it reduces the risk of unauthorized access and accidental changes to important resources.

## 2. Attack Surface

### The attack surface refers to all the possible entry points that an attacker could use to access a server. Examples include open network ports, running services, weak passwords, and outdated software. Reducing these entry points helps improve server security.

## 3. Default Deny Policy

### A Default Deny Policy means blocking incoming network traffic unless it is explicitly allowed by a firewall rule. It is safer because only approved services can receive incoming connections, reducing the opportunities for attackers to access the server.
