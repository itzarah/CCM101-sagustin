# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on deploying and using object storage with MinIO. MinIO was deployed using Docker, and a storage bucket was created to demonstrate how cloud object storage can be used for a photo-sharing application.

## Objectives

- Understand the three primary types of cloud storage.
- Differentiate Block Storage, File Storage, and Object Storage.
- Deploy a MinIO server using Docker.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a file to the bucket.
- Document the technical deployment steps.

## Tools Used

- KillerCoda
- Ubuntu/Linux Terminal
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Understanding different types of cloud storage.
- Using Linux command-line commands.
- Deploying applications using Docker.
- Using Docker environment variables.
- Working with MinIO object storage.
- Creating and managing storage buckets.
- Accessing services through forwarded ports.
- Documenting technical procedures using Markdown.
