|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |

## 1. Which cloud provider offers the broadest range of services? Explain your answer.

Among the three, AWS offers one of the widest ranges of cloud services. It has different services for computing, storage, networking, databases, security, AI, and many other cloud needs.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure for an organization that mainly uses Microsoft products. Azure works well with services like Windows Server, Microsoft 365, and Microsoft Entra ID, so it can be easier to manage and connect with the organization's existing systems.

## 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform (GCP) is widely recognized for its services in AI, Machine Learning, and Kubernetes. Some examples are Vertex AI, which is used for AI and ML development, and Google Kubernetes Engine (GKE), which helps manage containerized applications.

## 4. What similarities did you observe among the three cloud providers?

I noticed that all three cloud providers offer almost the same basic infrastructure services, such as computing, storage, networking, and identity management. The main difference is the name of the service and the features each provider offers, but they all aim to provide scalable and flexible cloud resources
