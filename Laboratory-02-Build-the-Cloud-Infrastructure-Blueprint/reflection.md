## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, I think compute is the most important component because it is where applications and services actually run. ## 2. How does Linux support cloud computing?

Linux supports cloud computing because it is commonly used for cloud servers. It is stable, flexible, and can handle different workloads. Linux also works well with tools for networking, automation, and containers, which are important in managing cloud systems.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it gives us a clear guide of what we need to do before deploying a system. It helps prevent mistakes and makes it easier to understand the configurations. If there is a problem later, we can also check the documentation to help find the cause.
