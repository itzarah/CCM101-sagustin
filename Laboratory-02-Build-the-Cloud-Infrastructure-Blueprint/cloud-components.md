# Cloud Infrastructure Components

## 1. Compute Resources

Compute resources are responsible for handling the processing tasks of a computer system. They allow the operating system, applications, and different workloads to perform their required operations.

Compute resources are essential in cloud computing because every application and service requires processing power to function. One advantage of cloud computing is that users can adjust the amount of computing power based on their current needs.

The CPU in the KillerCoda environment processes the Linux commands entered in the terminal and supports the applications and activities performed during the laboratory. Even with only one CPU core, it is sufficient for completing the required tasks.

## 2. Storage Resources

Storage resources provide space for keeping important system files, programs, configuration files, and user-created data. They allow information to remain available even when it is not actively being processed.

Storage is a major part of cloud infrastructure because applications and services need a reliable location for their data. Cloud storage also allows organizations to expand their storage capacity when more space is needed without purchasing additional physical disks.

The virtual disk in KillerCoda is used to hold the Ubuntu operating system, software packages, configurations, and files needed to complete the laboratory exercises. The available storage makes it possible to install and run the necessary tools inside the environment.

## 3. Networking Resources

Networking resources provide communication between computers, servers, applications, and other devices. They make it possible for systems to exchange information and connect to different services.

Networking is necessary for cloud computing because cloud-based systems constantly communicate with users, databases, application servers, and external services. A reliable network connection allows these resources to work together efficiently.

The KillerCoda environment uses its network interfaces and IP addresses to establish communication with the KillerCoda platform and other available network resources. This connectivity allows the Linux environment to perform activities that require network access.

## 4. Operating System

The operating system acts as the main software layer between the computer hardware and applications. It manages system resources and provides the necessary environment for users to execute commands and programs.

Operating systems are essential in cloud environments because servers require a stable platform where applications and services can operate. Linux is commonly used for cloud servers because it is reliable, flexible, and provides many useful command-line and server-management tools.

Ubuntu provides the working environment used in the KillerCoda laboratory. Through the Linux terminal, I can enter commands, manage files, execute programs, and perform the different activities required in the laboratory.
