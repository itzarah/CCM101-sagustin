# Automation Research

### 1. Bash Script

A Bash script is a file that contains Linux commands that can run together automatically. The "#!/bin/bash" line at the beginning tells the system to use the Bash interpreter to execute the script.

### 2. Variables

Variables store information, such as folder paths, that a script can use whenever needed. For example, "$BACKUP_DIR" stores the name of the backup directory, making the script easier to update without changing the same path in multiple places.

### 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script at a specified time. It is useful in cloud operations because it can automate repetitive tasks, such as creating backups, without requiring someone to run them manually.
