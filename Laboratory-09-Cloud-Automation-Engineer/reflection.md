# Reflection

This laboratory activity helped me understand why automation is important in cloud computing. When managing hundreds of cloud servers, performing every task manually takes a lot of time and can lead to human errors. By using Bash scripts and Cron jobs, repetitive tasks such as creating backups can run automatically. This helps make cloud operations more consistent and efficient.

However, automation also has risks. If a script contains a destructive command or an incorrect path, it could delete important files or damage many systems if executed across multiple servers. Before scheduling a script, it is important to review the code, test it in a safe environment, and make sure the commands are correct. Backups and proper access permissions are also important for reducing risks.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash scripting focuses on executing commands and automating tasks step by step. Docker Compose YAML describes services, configurations, networks, and other resources needed to run an application. Both tools are useful, but they solve different problems in cloud computing.

Throughout this semester, my understanding of cloud computing has improved. I learned that cloud computing involves more than simply storing files online. It also includes infrastructure, application deployment, data management, security, and automation. Each laboratory helped me understand how these areas work together to support reliable systems.

The role I enjoyed most was the Cloud Automation Engineer because I learned how to reduce repetitive work through scripting and scheduling. I also realized that automation requires careful planning, testing, and documentation. Overall, this activity taught me that cloud engineers need both technical skills and responsibility to manage systems effectively.
